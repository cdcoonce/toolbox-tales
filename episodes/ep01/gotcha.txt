A test suite was green, and every test named the defect it was meant to prevent. Then someone put one of those defects back into the code on purpose, and the suite stayed green. The tests had been passing all along without ever being able to fail: one patched out the very call it was checking, another asserted on its own expected string instead of the real output, and a third passed before the fix was even written. A green check only means something if a red one was possible, and nobody had ever seen these tests go red.
