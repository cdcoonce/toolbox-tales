detector-teeth-check proves a test can catch the defect it claims to catch. For each guarded behaviour it breaks the code on purpose (re-injects the defect), runs the suite, and requires it to go red on the test that is supposed to catch it, then puts the code back. A test that stays green while the defect is present has no teeth: it is decoration, and it gets fixed before the work ships. One control row changes something no test should care about, to prove the tool itself is not just breaking everything.
